KHYATHI — CREATIVE PORTFOLIO WEBSITE

Files
- index.html: the website
- assets/page-1.png ... page-7.png: visual pages exported from the supplied PDF

How to run
1. Extract the ZIP file.
2. Open index.html in a modern browser.

How to publish
Upload the whole folder (keeping the assets folder beside index.html) to any static host such as GitHub Pages, Netlify, or Vercel.

Notes
- The design preserves the original slide layout and aesthetic by using the supplied PDF pages as responsive page artwork.
- The contents links jump between sections. Phone, email and LinkedIn areas on the contact page are clickable.
- The PDF's page 6 is used for both Work Experience and Portfolio because it is the only page containing work samples. Replace the duplicate section with project-specific artwork when available.
